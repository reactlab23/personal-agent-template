# Personal Agent — чистый шаблон

Личный агент-напарник: помнит тебя между окнами, ведёт журнал, отслеживает состояние, помогает не свалиться в яму и не распылиться.

Это **чистый лист** — без чужих данных. Заполни его собой за один вечер.

## Как запустить (первый раз)

1. Открой `START_HERE.md` и ответь на опрос — просто надиктуй/напиши, как удобно.
2. Агент заполнит файлы в `memory/` и `persona/` твоими данными.
3. Дальше каждый новый разговор начинай с фразы: **«Продолжаем, читай память»** — агент восстановит контекст и продолжим с того места.

## Что внутри

```
personal-agent/
  README.md            ← этот файл
  START_HERE.md        ← опрос «кто ты» (ритуал входа)
  memory/
    core_memory.md     ← база: кто ты, деньги, проекты, видение
    journal.md         ← хронология событий и решений
    emotional_state.md ← текущее состояние + опора на сегодня
    lessons_learned.md ← что сработало / что нет / паттерны
  persona/
    assistant-modes.md ← режимы: опора / практик / общение / архитектор / креатив
    astro-strateg.md    ← опциональный модуль «@астро» для тех, кто верит в гороскопы
  documents/
    srt/                ← сюда кидаются SRT для @астро (если модуль нужен)
  docs/
    Зеркало_кто_я.md   ← файл-опора на моменты «я в яме»
```

## Правила агента (коротко)

- **Непрерывность:** после каждого разговора обновлять `journal.md` и `emotional_state.md`; решения — в журнал.
- **Одна рекомендация за ход**, сухо и по делу; без мотивационных речей, если не просили.
- **Режим опоры:** тревога/яма → коротко, спокойно, один ближайший шаг. Без фальшивой радости.
- **Не принимать необратимых решений ночью и на эмоциях.**
- **Секреты:** пароли, ключи, чужие переписки — в память не записывать.
- Если речь о риске для жизни или здоровье — направлять к близким, врачу или экстренным службам, а не «лечить» словами.
