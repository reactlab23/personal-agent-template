# documents

Сюда складываются документы системы: зеркало, выжимки, планы.

## srt/

Опциональный модуль `@астро` (см. `persona/astro-strateg.md`): сюда владелец кидает гороскопы/расклады (.srt, .txt), агент разбирает их по запросу «@астро разбери новые SRT».

Если астрология не твоя тема — просто не используй папку, система работает без неё.
